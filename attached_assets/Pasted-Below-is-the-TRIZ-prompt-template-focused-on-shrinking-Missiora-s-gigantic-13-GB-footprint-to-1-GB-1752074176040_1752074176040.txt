## 3) FUNCTION — Instrument → Object → Result.  
• **Three.js import** → whole library → 600 KB min + textures → multi-MB chunk (harmful)  [oai_citation:3‡discourse.threejs.org](https://discourse.threejs.org/t/bundle-size-reduction/38602?utm_source=chatgpt.com).  
• **node_modules** → devDependencies ship to prod → GBs wasted (harmful)  [oai_citation:4‡tsh.io](https://tsh.io/blog/reduce-node-modules-for-better-performance/?utm_source=chatgpt.com).  
• **Route lazy import** → async chunk → smaller first payload (helpful)  [oai_citation:5‡router.vuejs.org](https://router.vuejs.org/guide/advanced/lazy-loading.html?utm_source=chatgpt.com).  
• ✅ *Debug Tip:* run `vite build --report` then open visualiser to spot > 1 MB modules.

## 4) EVENT — Cause-effect loops.  
• **E1:** Build pipeline emits `dist/assets` ≈ 13 GB → mobile loads > 30 s → loader never hides.  
  – *Test:* Browser throttled 4G; record Network waterfall; fail if Time-to-Interactive > 5 s.  
• **E2:** Remove unused locale data from Moment.js → bundle drops 300 KB → TTI improves 400 ms.  
  – *Test:* Jest + `expect(assetSize('moment')).toBeLessThan(50*1024)`.

## 5) RESOURCE — Reveal hidden or overlooked.  
• - Use **dynamic imports** for both route & heavy libs (`import('three/examples/…')`) so only MR view loads graphics  [oai_citation:6‡vuejs.org](https://vuejs.org/guide/best-practices/performance?utm_source=chatgpt.com).  
• - Run `npm prune --production` & `--omit=dev` in Docker build  [oai_citation:7‡stackoverflow.com](https://stackoverflow.com/questions/50206572/how-to-reduce-node-modules-in-npm?utm_source=chatgpt.com).  
• - Off-load 3D assets / models to CDN with HTTP-range requests.  
• - Swap Terser → **esbuild** for faster & tighter minification  [oai_citation:8‡dev.to](https://dev.to/yoskutik/extremely-reducing-the-size-of-npm-package-3420?utm_source=chatgpt.com).  
• - Turn on tree-shaking + side-effects=false in Three.js build  [oai_citation:9‡discourse.threejs.org](https://discourse.threejs.org/t/how-to-reduce-bundle-size-with-webpack/14607?utm_source=chatgpt.com).

## 6) IDEAL FINAL RESULT (ИКР).  
• First paint < 1 s, TTI < 3 s on 4G.  
• Full app bundle ≤ 1 GB; per-page JS < 250 KB.  
• Loader fade-out triggered by `AROverlay.onReady()` within 500 ms.  
• Verified by Lighthouse “Performance ≥ 90” mobile.

## 7) CONTRADICTION.  
Need high-fidelity MR assets **vs** need tiny payload.  
• **Experiment:** Stream GLTF models progressively; show low-poly placeholder until full load; measure FPS drop & user perception.
