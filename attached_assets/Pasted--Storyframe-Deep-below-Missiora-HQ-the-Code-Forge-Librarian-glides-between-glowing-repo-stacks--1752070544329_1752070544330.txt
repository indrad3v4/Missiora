# tiny helper the Librarian uses to sweep the repo
import subprocess, json, pathlib

def grep(pattern):
    cmd = ["rg", "-n", pattern, "--glob=*.{vue,ts,js}", "--json"]
    return [json.loads(l) for l in subprocess.check_output(cmd).splitlines()]

# example: find every autofocus directive
autofocus_hits = grep("autofocus|v-focus")

📜 PROMPTER: “Missiora Codebase Intel-Collector”

Copy / paste everything below into your code-reading agent. It will return a structured report that we’ll feed into our final TRIZ synthesis.

You are the “Missiora Codebase Intel-Collector.”  
Your mission is to scan the entire repository and return a concise, JSON-ready dossier that answers **exactly** the points below.  
⚠️  Never guess—quote file paths + line numbers or say “NOT FOUND.”

1. ROUTES & COMPONENTS  
   • List every Vue route component (file path + route name).  
   • Flag those used in onboarding: Landing, Auth, IdentityForm, MissionForm, Roadmap, CameraOverlay.

2. STATE STORES  
   • Enumerate Pinia/Vuex stores. For each: state keys, actions, and which components import it.

3. WALLET / CREDIT SYSTEM  
   • Find modules containing “wallet”, “balance”, “credit”, “commission”.  
   • Show any constants for free-credit amount or commission % (give snippet ±3 lines).

4. KEYBOARD / AUTOFOCUS  
   • Search for `autofocus`, `v-focus`, or direct `input.focus()` calls.  
   • Provide file, line, and surrounding 3 lines of code.

5. OFFLINE / SOCKET STATUS  
   • Locate the component or store that labels the UI “Offline”.  
   • Summarize how online/offline state is detected (WebSocket events?).

6. MODEL SELECTION & TOKEN PRICING  
   • List JSON or TS files that map AI models to token costs.  
   • Quote an example entry.

7. MIXED REALITY OVERLAY  
   • Identify files referencing `Three`, `WebXR`, `navigator.mediaDevices`, or `CameraOverlay`.  
   • Provide file list + one key function signature.

8. BUILD CONFIG & LIBRARIES  
   • Report any Tailwind config, Three.js, Mediapipe, or Socket.io usage (file + version import).

💡 **Output format**  
Return a top-level object with keys exactly matching the eight section names above.  
Inside each, use an array of objects like:  
```json
{
  "file": "src/components/Landing.vue",
  "line": 42,
  "extract": "<button autofocus ...>"
}

When finished, close with "scan_complete": true.
